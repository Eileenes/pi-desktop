它做什么

What it does

桌面端负责窗口、工作区和授权。会话循环、工具和模型协议交给已经发布的 Pi 包，不在本仓库里改上游。

The desktop owns the window, the workspace, and authorization. The session loop, tools, and model protocol come from the published Pi package. This repository does not patch upstream.

安全边界

Security boundary

渲染进程不能直接碰文件系统、子进程或网络。它只能走白名单 IPC。打开项目要先确认信任；每次内置工具调用要单独点头。已存密钥不会回到渲染进程。

The renderer cannot touch the filesystem, child processes, or the network directly. It talks through a allowlisted IPC bridge. Opening a project requires trust. Each built-in tool call needs its own approval. Stored credentials never return to the renderer.

审计只记元数据。更新源锁在本项目的 GitHub Releases。只打开你信任的目录——项目说明和扩展可以改变代理行为。

Audit logs keep metadata only. The update feed is this project’s GitHub Releases. Only open directories you trust — project instructions and extensions can change agent behavior.
